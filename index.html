Automated Analysis Mode

This mode runs a simplified JavaScript version of the simulation model. It compares four strategy archetypes across repeated games and outputs final cash, delivery success, failed deliveries, and a boxplot-style visualization.

Reference results are from the Python simulation: 200 games per strategy, seed = 42. Browser simulation is approximate because JavaScript random generation will not match Python’s seeded output exactly.
